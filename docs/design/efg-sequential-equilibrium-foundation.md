# Sequential-equilibrium foundation

This note records the implemented boundary of
`Observed/SequentialEquilibrium.lean`. The module is explicit and
experimental; it is not imported by `EconCSLib.lean` or a public equilibrium
facade.

## Representation

| Textbook object | Lean representation | Important boundary |
|---|---|---|
| node in an information set | `ObservedGame.DecisionInfoWitness` | contains a complete history occurrence, so endpoint merging cannot erase belief points |
| raw belief data | `RawBeliefSystem` | nonnegative weights only; no normalization claim |
| belief system | `BeliefSystem` | a `PMF` at every player information state |
| assessment | `Assessment` | behavioral profile plus normalized beliefs |
| completely mixed profile | `BehavioralProfile.IsCompletelyMixed` | every abstract information action has positive mass |
| reached-set Bayes belief | `FiniteSequentialHypotheses.bayesBelief` | requires a proof of positive total reach |
| consistency | `Assessment.IsKrepsWilsonConsistent` | one completely mixed sequence, positive perturbation reach, and pointwise topological convergence |
| sequential rationality | `Assessment.IsSequentiallyRationalFor` | parameterized by a local continuation-value evaluator |

`ObservedGame.FiniteEFGHypotheses` excludes ghost information states through
`allDecisionInfoRepresented` and makes the occurrence carrier finite through
its uniform history bound and locally finite action fibers. Chance is supplied
by `ObservedChanceGame`; the behavioral history policy uses that declared
kernel exactly.

## Zero-probability information sets

`bayesBelief` cannot be constructed at an information state whose reach
denominator is zero. A consistent limiting assessment instead provides
beliefs there as limits of Bayes beliefs generated by a common completely
mixed perturbation sequence. Thus the API does not silently select arbitrary
off-path beliefs by dividing by zero.

Completely mixed player behavior alone does not make zero-probability chance
branches positive. The consistency certificate therefore records positive
total information-set reach for every perturbation explicitly.

## Current theorem strength

The module proves normalization, the finite Bayes formula, convergence
projections, and the two defining projections from evaluator-relative
sequential equilibrium.

It deliberately proves no implication to Nash or SPE. The missing bridge is a
canonical evaluator obtained from conditional expected continuation utility,
together with a theorem identifying its local optimality condition with the
standard finite perfect-recall definition. Only after that bridge and the
usual Nash consequence are formalized should this module enter a reusable
equilibrium facade.

## Sources

The terminology and consistency architecture follow Kreps and Wilson,
“Sequential Equilibria,” *Econometrica* 50(4), 1982, pp. 863--894,
and the finite extensive-form presentation in Laraki, Renault, and Sorin,
*Mathematical Foundations of Game Theory*, Definition 6.4.5.
