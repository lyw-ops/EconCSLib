# Counterexample evidence

No counterexample evidence is asserted in Phase 1. Phase 2 may add pinned,
reviewed records classified as `GENUINE_COUNTEREXAMPLE`,
`LEGITIMATE_EXCEPTION`, `DOMAIN_SPECIFIC`, `COMPATIBILITY_CONSTRAINT`,
`GENERATED_CODE`, `LEGACY_CODE`, or `INCONCLUSIVE`. Classification must remain
independent of rule strength, finding priority, and evidence class.
